# FestivalPulse

## Dependencies

| Dependency | Version |
|---|---|
| Java | 17 |
| Spring Boot | 4.1.0 |
| spring-boot-starter-web | managed by Spring Boot |
| spring-boot-starter-data-jpa | managed by Spring Boot |
| spring-boot-starter-validation | managed by Spring Boot |
| spring-boot-starter-actuator | managed by Spring Boot |
| H2 Database | managed by Spring Boot |
| Jackson XML (jackson-dataformat-xml) | managed by Spring Boot |
| SpringDoc OpenAPI (Swagger UI) | 3.0.3 |

## Running the project

```bash
./mvnw spring-boot-run
```
